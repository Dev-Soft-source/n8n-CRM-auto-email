Lead capture test form

Sends a POST with JSON to your n8n webhook (path lead-capture), matching the fields in your implementation guide.

Webhook

Test URL (…/webhook-test/lead-capture): in n8n, open the workflow, select the Webhook node, click Listen for test event, then submit (each new listen session may need a fresh click).

Production URL (…/webhook/lead-capture): turn the workflow Active, then copy the webhook URL from the node. The first node must be a Webhook (POST)—not Form Trigger; those use different URLs and behavior.

Webhook URL is stored in this browser (localStorage).

Recommended: from test-web-app run npm start, open http://127.0.0.1:3456, keep “server proxy” checked, then submit. Uncheck only if n8n allows your origin in CORS or you use a same-origin backend.
